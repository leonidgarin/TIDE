    TIDE - Time Invariant Discretization Engine.

    Bins mixed-type features (numbers, strings, missing values) so that the bins are stable over time, and encodes them with Weight of Evidence. For the continuous part the following hard constraints hold in every period:

    • the event rate is monotonic over the bins, in the same direction in all periods, so event-rate (WoE) curves never cross;
    • adjacent bins differ in event rate by at least min_er_delta;
    • every bin holds at least min_sample_rate of the period's rows and at least min_class_obs events and non-events.

    By default, categories and missing values get their own bins. With cat_strategy="tide", all bins (continuous, categorical and missing) are merged until the constraints hold for all of them.

    Parameters:

    Name Type Description Default
    min_sample_rate float

    Minimum share of a period's rows in each bin, checked in every period.

    		 0.05
    min_class_obs int

    Minimum number of events and of non-events in each bin, in every period.

    		 1
    min_er_delta float

    Minimum event-rate gap between adjacent continuous bins, in every period.

    		 0.0
    trend ('auto', 'pos', 'neg')

    Direction of the event rate over the continuous bins. "auto" uses the sign of a linear fit of event rate vs. quantile-bin index. A dict maps feature names to "pos" / "neg" / "auto"; features that are not listed use "auto".

    		 "auto"
    max_unique int

    If the continuous part has more unique values than this, the candidate split points are n_quantiles quantiles instead of all unique values.

    		 1000
    n_quantiles int

    Number of quantile candidate points used when max_unique is exceeded.

    		 200
    n_trend_bins 'log' or int

    Number of quantile bins for trend detection. "log" means max(3, ceil(ln(n_rows))).

    		 "log"
    min_bound float or 'col_min' / 'col_max'

    Outer bounds of the first and last continuous bins. "col_min" / "col_max" use the training minimum / maximum, so unseen values beyond them are unknown.

    		 -inf / inf
    max_bound float or 'col_min' / 'col_max'

    Outer bounds of the first and last continuous bins. "col_min" / "col_max" use the training minimum / maximum, so unseen values beyond them are unknown.

    		 -inf / inf
    missing_values list or dict

    Extra values treated as missing, e.g. [-1, "N/A"]. NaN, None, pd.NA and NaT are always missing. A dict maps feature names to lists.

    		 ()
    cat_values list or dict

    Numeric values treated as categories, e.g. [-999]. Strings and bools are always categories. A dict maps feature names to lists.

    		 ()
    missing_strategy ('separate_bin', 'worst_bin', 'best_bin')

    "separate_bin": missing values get their own bin (if any are present). "worst_bin" / "best_bin": if the missing share is below missing_rate, missing values join the continuous bin with the highest / lowest event rate and take part in the scan; otherwise they get their own bin.

    		 "separate_bin"
    missing_rate float

    Threshold for "worst_bin" / "best_bin".

    		 0.05
    cat_strategy ('separate_bin', 'chi-squared', 'tide')

    "separate_bin": every category is its own bin; curves may cross. "chi-squared": categories are merged with ChiMerge. "tide": all bins are merged until every constraint holds for all bins.

    		 "separate_bin"
    alpha_significance float

    p-value threshold for ChiMerge.

    		 0.05
    user_bins dict or None

    {feature: bins_dict}. These features are not searched; their bins are applied as given. A warning lists training values that fall in no bin.

    		 None
    handle_unknown ('keep', 'worst', 'best', 'missing_worst', 'missing_best')

    How transform treats values that fall in no bin. "keep" leaves the raw value, "worst" / "best" use the lowest / highest WoE, and "missing_worst" / "missing_best" use the WoE of the bin with missing values, else the lowest / highest WoE. It is read only in transform, so it can be changed with set_params after fitting.

    		 "keep"
    n_jobs int or None

    Number of parallel jobs over features (joblib). -1 uses all cores.

    		 None
    verbose bool

    Show a progress bar during fit.

    		 False
